# Яндекс Пульс (ветка `pulse`)

Отдельное приложение на основе «Яндекс Маяка» (ветка `ya`): свой пакет `ru.mayak.pulse`,
ставится рядом и ничего не обновляет. Главное отличие — новый транспорт **облачный ящик**:
телефон и нода обмениваются пачками пакетов через объектное хранилище
**Яндекс Облака** (`storage.yandexcloud.net`, тип `ycloud`) и/или **VK Cloud**
(`hb.ru-msk.vkcs.cloud`, тип `vkcloud`). Для оператора это обычная загрузка файлов в облако,
а скорость намного выше, чем у документов: данные идут пачками до 1 МБ, параллельно,
с упреждающим чтением. Основной канал — VK Cloud (приоритет 130: запросы у VK бесплатные, платится только трафик), Яндекс Облако — запасной (120): ядро переходит на него, только когда VK не отвечает.

Адрес ящика: `КЛЮЧ:СЕКРЕТ@бакет/папка` (статический ключ сервисного аккаунта с правом
записи в бакет). Шифрует трафик слой OpenFlux ключом профиля, как и для остальных транспортов.

- ядро: `patches/core-0006-pulse-cloud-transport.patch` (пакет `transport/s3box`, подпись
  S3 SigV4 на стандартной библиотеке, проверена эталоном AWS);
- нода: `deploy/node-install.sh` понимает строки `ycloud=` и `vkcloud=`; ядро для сервера
  собирает `.github/workflows/build-pulse-node.yml` в пре-релиз `node-v9.1.0` этого репозитория;
- APK: `.github/workflows/build-pulse.yml`, пре-релизы `pulse-build-N`.
