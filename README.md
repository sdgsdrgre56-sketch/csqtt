# Пульсар

Свой туннель через облачное хранилище VK Cloud: работает там, где открыт только VK.

- `core/` — ядро (Go, только стандартная библиотека): ящик в облаке, мультиплексор потоков, шифрование AES-256-GCM, SOCKS5.
- `cmd/pulsar` — программа: `server`, `client`, `link`, `check`.
- `server/install.sh` — установка сервера одной командой.
- `android/` — приложение для телефона.

Сервер сам скачивает сайты на полной скорости и заливает их в облако крупными кусками,
поэтому задержка облака (~0,5 с) почти не режет скорость загрузки.
